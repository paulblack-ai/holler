<objective>
Add an LLM endpoint health check to `holler init` so that users get a clear, actionable
warning when no LLM is reachable instead of the call silently stalling later.

Purpose: Currently `holler call` stalls with no output when Ollama (or another LLM) is not
running. Catching this at init time gives the user a chance to fix it before they get stuck.

Output: Updated `holler/cli/commands.py` with `_check_llm_endpoint()` helper, updated tests.
</objective>
